# Changelog

All notable changes to GPU VRAM Monitor will be documented in this file.

## Unreleased

- Expanded open-source maintenance documentation.
- Added contribution, security, roadmap, and CI guidance.

## v0.1.0

- Initial Windows Forms desktop overlay.
- Added VRAM memory-junction temperature display.
- Added GPU core temperature, board power, and core clock telemetry.
- Added radiator fan control through LibreHardwareMonitor.
- Added manual fan slider and automatic fan curve.
- Added NVIDIA power-limit presets through `nvidia-smi`.
